# Support

## Website problems

For reproducible bugs, accessibility problems or content errors, open a GitHub issue using the appropriate template. Include the affected URL, browser/device, expected result and actual result. Screenshots must not contain applicant data or other private information.

## Join applications and privacy requests

Email **ieesec.ihu@gmail.com** for:

- Questions about an existing join application.
- Requests to access, correct or delete application information.
- Problems that require sharing personal information.

Do not post application details in public issues.

## Security

Potential vulnerabilities and leaked secrets must follow [SECURITY.md](SECURITY.md), not the public issue tracker.

## Community

General community discussion and event announcements are available through the Discord invitation linked from the website footer. Discord is not the correct place for security reports or privacy requests.
