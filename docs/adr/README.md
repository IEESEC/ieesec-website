# Architecture decision records

ADRs preserve the context behind decisions that are costly to reverse. They describe why the current implementation exists; they are not a substitute for code or operational guides.

## Lifecycle

Statuses are `Proposed`, `Accepted`, `Superseded` or `Deprecated`. Never rewrite an accepted decision to hide a change. Add a new ADR and link the superseded record.

Use the next four-digit number and include: status, date, context, decision, consequences and follow-up conditions.
